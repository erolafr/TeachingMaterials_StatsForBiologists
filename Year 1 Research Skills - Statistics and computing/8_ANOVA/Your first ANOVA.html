Aim

This practical is designed to help you assimilate the basic ideas of ANOVA and learn the main R functions used to carry out and interpret an ANOVA.

The practical follows the same logic as the lecture: we start from a research question, explore the data graphically, check the assumptions, fit the model, and then interpret the results in terms of both statistical significance and biological meaning.

After finishing, you will be ready to understand scientific articles that have used this analysis. I have prepared a folder with articles you are ready to understand now. Pick one of them and try to understand what they did and how the ANOVA results are visualized.

1. Introduction

In this practical, we will use analysis of variance to test whether the mean of a quantitative response differs among more than two groups. ANOVA is especially useful in designed experiments, where the explanatory variable is categorical and the response variable is continuous.

2. Learning outcomes

By the end of this practical, students should be able to:

  • identify when ANOVA is the appropriate test,
  • formulate a simple research question and hypotheses,
  • prepare the data for analysis in R,
  • check the main ANOVA assumptions,
  • run a one-way ANOVA using aov(),
  • interpret the ANOVA table with summary(),
  • perform post hoc comparisons using TukeyHSD(),
  • distinguish between statistical significance and biological importance.

6. Prepare the data

The treatment variable should be a factor, which it already is in this example. Still, it is good practice to check it and declare it as so.

is.factor(mydata$Treatment)
[1] TRUE

If it was not a factor declare it:

mydata$Treatment <- as.factor(mydata$Treatment)

Check for missing values:

sum(is.na(mydata))
[1] 0

Question for students

Why is it important that the treatment is treated as a factor?

Possible answer: Because ANOVA compares group means across categories. If the variable were treated as numeric, R might interpret it as continuous, which would not match the experimental design. This will be a problem if for example our levels are called “1”. “2”, “3”, “4”.

7. Check ANOVA assumptions

ANOVA assumes:

  1. the residuals are approximately normally distributed,
  2. the variances are similar across groups.

7.1 Fit the model first

This is the structure we use to build the anova model. Make sure you understand this structure (it will appear again later)

mod <- aov(Response ~ Treatment, data = mydata)

7.2 Normality

plot(mod, which = 2)
shapiro.test(residuals(mod))

8. Run the one-way ANOVA

mod <- aov(Response ~ Treatment, data = mydata)
summary(mod)
            Df Sum Sq Mean Sq F value   Pr(>F)

Residuals   44  39.97    0.91                     
---
Signif. codes:  0 '***' 0.001 '**' 0.01 '*' 0.05 '.' 0.1 ' ' 1

What this code does

  • aov() fits the ANOVA model.
  • Response ~ Treatment tells R that the response variable is explained by the factor Treatment.
  • summary() prints the ANOVA table, including sums of squares, degrees of freedom, mean squares, the F-ratio, and the p-value.

Questions for students

  1. Is the p-value below 0.05?
  2. What does that mean?
  3. Does a significant ANOVA tell us which groups are different, or only that there is at least one difference?
  4. What is the difference between using summary(mod) and just mod ? Run both in your console and compare the outputs.
  5. Could you calculate by hand the ANOVA table?

Possible answers: 1) In this simulated dataset, yes, it should usually be below 0.05. 2) It means that we reject the null hypothesis that all group means are equal. 3) It only tells us that at least one group differs; it does not identify the specific pairs. 4) mod prints the fitted model object and basic information about the model formula and residuals. summary(mod) produces the full ANOVA table, including sums of squares, degrees of freedom, mean squares, the F-ratio, and the p-value. The summary output is what we normally use to interpret the statistical results.5) i strongly encourage you to try at least once. I did it and it deeply helped me understand everything on it.

Questions for students

  • Which groups differ significantly?

  • Are all pairwise comparisons significant, or only some of them?

  • How should we interpret a comparison with p > 0.05?

  • A common way to visualize these results is to use letters for homogeneous groups. Assign letters to each group following this rule: start with the smallest means (at the top of the table above). If two groups are not significantly different, assign an “a” to both. If they are significantly different, assign an “a” to the smaller one and a “b” to the larger one. Then continue comparing the next groups. If a group shares similarities with two different groups, it can receive two letters (for example, “ab”). This means that the group is not significantly different from groups labelled with “a” nor from groups labelled with “b”, even if the “a” and “b” groups are significantly different from each other.

Possible answers: Usually the biggest differences, such as A vs D and B vs D, are significant. Smaller differences, such as A vs B, may not be significant. A p-value above 0.05 means that pair is not clearly different in this dataset.

10. How to interpret the ANOVA table

The ANOVA table partitions the total variation into:

  • variation explained by the factor,
  • residual variation or error.

The F-ratio compares the variation explained by the factor with the unexplained variation. If the F-ratio is large enough, we reject the null hypothesis.

This is the central idea of ANOVA: we are comparing variation between groups with variation within groups.

Question for students

Why does ANOVA use a ratio of variances instead of comparing means directly?

Possible answer: Because the ratio tells us whether the differences between group means are large relative to the natural spread within groups. If between-group variation is much larger than within-group variation, that suggests a real treatment effect. So, truly, calling it ANOVA is misleading, it is not just observing how the variance changes, but also the means difference and the sample size.
